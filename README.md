# Dice Mini App (режим «поднос»)

Кости лежат на столе и ведут себя так, будто стол = экран телефона: наклон сдвигает их,
тряска заставляет дребезжать. Когда рука останавливается, кости подбрасываются, катятся и
останавливаются. Результат честный: число выбирается RNG (rng.js) или сервером (api.js),
а физика подгоняется под него: числа на гранях меняются, пока кость в воздухе.

1. Локальная проверка (ES-модули не работают через двойной клик):
   python -m http.server 8000   ->   http://localhost:8000
2. Залей ВСЕ файлы в репозиторий GitHub, включи Pages (ветка main, папка /root).
3. В BotFather поменяй URL, увеличив ?v=N, чтобы обойти кэш Telegram.

Настройка ощущения (config.js):
- LIVE.DYN_GAIN   сила дребезга от тряски (5; больше = сильнее)
- LIVE.TILT_GAIN  как сильно кости едут при наклоне (0.6; 0 = стол всегда ровный)
- SHAKE.CALM_MS   сколько ждать после остановки руки до броска (220)
- SHAKE.START_DEV порог начала тряски (5 м/с²)

Диагностика сверху экрана: ?debug=0 скрывает её.
Если кости едут при наклоне в обратную сторону: добавь к URL ?flip=1 (или ?flip=0).
Новые файлы: motion.js, world.js, forecast.js. shake.js и physics.js переписаны.
